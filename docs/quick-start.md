# Quick Start

## Executive Summary

- Install dependencies with `bun install`.
- Run the local development server with `bun run dev`.
- Run `bun run check` before handing off changes.
- Build the static site with `bun run build`.

## Setup

```bash
bun install
```

## Development

```bash
bun run dev
```

Open the local URL printed by Next.js.

## Verification

```bash
bun run check
```

## Static Build

```bash
bun run build
```

The exported files are written to `out/`.
