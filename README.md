# What Is Offside?

A static Next.js guide that explains football's offside law with slide-based teaching, responsive pitch visuals, and an interactive decision lab.

## Install

`bun install`

## Usage

Run the local app:

```bash
bun run dev
```

Build the static site:

```bash
bun run build
```

The production artifact is written to `out/`.
